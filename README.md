# Travelling-Salesman-Optimization
This project was developed as part of a university hackathon held at Istanbul Bilgi University. The primary objective of the project is to address the Travelling Salesman Problem (TSP) by applying algorithmic optimization techniques and computational problem-solving approaches.

The solution focuses on minimizing the total travel distance between multiple locations while ensuring efficiency and real-life applicability. Throughout the development process, different optimization strategies were evaluated to balance solution quality and computational performance.

By simulating realistic constraints and route-planning scenarios, the project demonstrates how theoretical optimization problems such as TSP can be adapted to practical use cases, including logistics, delivery systems, and route planning. 

The project also highlights teamwork, ownership of responsibilities and time-constrained development skills gained during the hackathon environment.
